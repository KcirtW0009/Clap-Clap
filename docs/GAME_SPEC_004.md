## 1. 游戏概览

- 单机 1v1 人机对战（玩家 P1 vs AI P2），纯 HTML/CSS/JS，浏览器打开 `index.html` 即玩。
- 引擎支持 2–9 人（多人 UI 待做，见 §9）。
- 核心循环：**准备（三选一出招）→ 锁定 → 同步结算 → 战报 → 下一回合**，直至一方 HP 归零。
- 状态机：`READY → LOCK → RESULT → (下一回合) READY`。

## 2. 动作系统（每回合三选一）

| 动作 | type | 说明 |
|:---|:---|:---|
| **接取** | `gather` | 从金/木/水/火/土任选一种，获得 1 枚 |
| **使用** | `use` | 选元素 → 选路线，按路线消耗资源发动效果 |
| **防御** | `defend` | 本回合**所有非穿防伤害全额归零**；驱散自身灼烧/种子/水渍；规避水渍判定 |

- **铁律**：一回合只能选一个动作，接取与使用不可兼得。
- 动作内部结构 `{ type, element, route, amount, targets }`；引擎 `normalizeAction` 归一化缺失字段。
- **强制改防御**（记入 `forcedChanges`）：被束缚却选择三选一之外的动作、资源不足、重复铸造已有武器、对已束缚目标施放藤蔓束缚。
- 成本类型：固定数值 `cost: N` ／ 全部 `cost: 'all'` ／ 加特林按量 `cost: 'amount'` ／ 穿甲弹计数 `cost: 'ap'`。

### 判定表（双方动作同时结算）

| 我方 \ 对方 | 使用 | 接取 | 防御 |
|:---|:---|:---|:---|
| **使用** | 双方效果同时生效，互承伤害 | 攻击正常生效；接取方照常 +1 元素 | 非穿防伤害归零；状态按各自规则处理 |
| **接取** | 同上 | 双方各 +1 | 接取成功 |
| **防御** | 同上 | 对方接取成功 | 无事发生 |

> 接取不会被伤害打断（照常获得元素），但会照常承受伤害。

## 3. 资源系统

| 资源 | 说明 |
|:---|:---|
| **元素** | `{ Jin, Mu, Shui, Huo, Tu }` 各自独立计数，上限 **9**（`MAX_ELEMENT`） |
| **HP** | 半点制（0.5 步进）：初始 **3**，上限成长至 **5.0**（仅生命之泉可提升 maxHp）；所有伤害恒为整数 |
| **武器** | `hasGatling` 加特林 ／ `hasDualPistols` 双枪 ／ `armorPiercing` 穿甲弹计数 |
| **状态** | 束缚 `bindTurns` ／ 种子 `seedTurns+seedOwner` ／ 灼烧 `burnTurns` ／ 水渍 `wetTurns` ／ 岩壳 `shellLayers`(0–5) ／ 岩脉共鸣 `hasVein`(永久) |
| **lastAction** | 上回合实际执行的动作快照（供束缚复读判定） |

胜负：任一方 `hp ≤ 0` 即败；同时归零平局；多人为最后存活者胜。

## 4. 五元素路线总表

### 4.1 金（Jin）— 锻造 / 物理爆发 / 破防

| route | 名称 | 消耗 | 效果 |
|:---|:---|:---|:---|
| `attack` | 金之斩 | 1金 | 1 伤害，可被防御。**兼职**：被束缚时的挣脱技（见 §5.1） |
| `craftGatling` | 铸造加特林 | 1金 | 获得永久武器加特林（已有则不可再铸） |
| `gatlingFire` | 加特林射击 | N金 | 发射 **2N 发子弹**集火单体，每发 1 伤、独立被防御归零 |
| `craftDual` | 铸造双枪 | 1金 | 获得永久武器双枪（已有则不可再铸） |
| `dualFire` | 双枪射击 | 1金 | 2 发各 1 伤；**1v1 可集火同一目标（合计 2 伤），多人必须分流两个目标** |
| `craftAP` | 铸造穿甲弹 | 1金 | 穿甲弹 +1 |
| `apFire` | 穿甲射击 | 1穿甲弹 | **1 伤害无视一切防御**（穿透防御/木墙/岩壳）；命中荆棘之墙时将其击碎且伤害提升为 2 |

核心特色：先投资回合锻造，后期获得爆发能力。加特林=屯金一波流，双枪=稳定两点，穿甲弹=破防利器。

### 4.2 木（Mu）— 控制 / 干扰 / 防守反击

| route | 名称 | 消耗 | 效果 |
|:---|:---|:---|:---|
| `attack` | 木之刺 | 1木 | 1 伤害，可被防御 |
| `bind` | 藤蔓束缚 | 1木 | **无伤害、穿透防御**，束缚目标 **2 个整回合**（细则见 §5.1）。**不可叠加**：已束缚目标免疫，施放无效且**不消耗木** |
| `seed` | 种子寄生 | 2木 | 1 伤害（可被防御）+ 植入种子：回合结束时随机偷取目标 1 枚元素（持续 1 回合）。对方用**防御**可同时抵消伤害并驱散种子 |
| `thorn` | 荆棘之墙 | 2木 | 本回合免疫全部非穿防伤害；每个攻击过自己的攻击者被反弹 1 伤（走伤害管线，可被其防御）。穿甲弹击碎墙：伤害变 2 且不反弹 |

核心特色：不求直伤，以束缚/偷取/反伤打乱对手节奏。

### 4.3 火（Huo）— 爆发 / AOE / 高风险高回报

| route | 名称 | 消耗 | 效果 |
|:---|:---|:---|:---|
| `fireball` | 火球术 | 1火 | 1 伤害，可被防御 |
| `fireRain` | 火球雨 | **全部火** | 每 1 火指定 1 个**不同**目标各 1 伤（单一目标只能被指定 1 次）；1v1 时只打出 1 伤（多余火溢出） |
| `blaze` | 烈焰爆发 | 2火 | **3 伤害**（可被防御）+ 自身反噬 1 点（无视防御、不吃自身岩壳） |
| `burn` | 灼烧烙印 | 2火 | 1 伤害 + 附加**灼烧 2 回合**：每回合末 1 伤**无视防御**；被防御时直伤归 0 但灼烧先附加再被该次防御驱散 |

核心特色：火球雨=多人压血线，烈焰爆发=赌命斩杀，灼烧=慢性逼防。

### 4.4 水（Shui）— 渗透 / 回复 / 资源破坏

| route | 名称 | 消耗 | 效果 |
|:---|:---|:---|:---|

| `scour` | 冲刷 | 2水 | 1 伤害（可被防御）。**若命中**（目标未防御且未被墙/岩完全格挡）→ 从目标金/木/火/土中**随机销毁 1 枚**（销毁而非转移）。岩壳吸收不影响命中判定；目标四系皆空则无事发生 |
| `spring` | 生命之泉 | 2水 | 自体路线。`hp < maxHp`：回复 1；已满血：`maxHp +1`（封顶 5.0）并回复 0.5；双满则浪费 |

核心特色：渗透磨血逼防、冲刷拆资源、泉水续航/成长。

### 4.5 土（Tu）— 防守反击 / 岩壳 / 后期永动

| route | 名称 | 消耗 | 效果 |
|:---|:---|:---|:---|
| `attack` | 土弹 | 1土 | 1 伤害，可被防御 |

| `thornRock` | 荆棘岩 | 2土 | 自体路线。本回合**完全免非穿防伤害**（穿甲弹照常造成伤害）；本回合每个攻击过自己的攻击者受到 **2 点反弹（无视防御）**；若有岩壳 ≥1 层，反弹提升为 **3 点并消耗 1 层** |
| `vein` | 岩脉共鸣 | 3土 | **永久被动**：① 每回合开始自动凝聚 1 层岩壳（封顶 5）；② 选择防御且本回合被攻击过时，每攻击者受 1 点反弹（无视防御） |

核心特色：叠壳消耗流、反击威慑、后期永动。

## 5. 状态效果细则

### 5.1 束缚（bind）— V3.1 修订版

- 施加：藤蔓束缚，1 木，无伤害、穿透防御，`bindTurns = 2`（实际锁住施加后的**连续 2 个整回合**）。
- **三选一**（束缚期间每回合只能选择其一）：
  1. **防御**；
  2. **复读上回合选定的动作**（type/element/route/amount/targets 必须与 `lastAction` 完全一致，且资源仍需足够；复读接取也放行）；
  3. **金之斩挣脱**：消耗 1 金，解除束缚并正常造成 1 伤。
- **不可叠加**：目标已处于束缚状态时免疫新的藤蔓束缚——路线按钮直接禁用；强行提交会被强制防御且**不消耗木**（战报提示"束缚不可叠加"）。
- **受击解绑（严格版）**：束缚中本回合因他人伤害**实际掉血**（含灼烧/水渍 tick）则束缚立即断裂；被防御归零的伤害不触发。
- 无金时无法主动挣脱，也无法接取攒金（复读除外）——这是束缚的核心压制面。
- 解除后即可再次被施加（非永久禁用）。

### 5.2 灼烧（burn）＆ 种子（seed）

- 灼烧：附加后每回合末（未防御时）受 1 伤无视防御，持续 2 回合；防御动作驱散（剩余层数清零）。
- 种子：植入后 1 回合，回合末（未防御时）随机偷走 1 枚元素转移给施术者；防御动作同时抵消直伤并驱散。

### 5.3 水渍（wet）

```
第 N 回合：A 对 B 渗透 → B 获得水渍（施加本身无视防御、无伤害事件）
第 N+1 回合末：
  ├─ B 该回合选择了防御 → 完全规避，水渍清除
  └─ B 未防御 → 受 1 伤（无视防御、无视岩壳），水渍清除
```

- 只刷新一层，重复施加不叠层。
- 施加水渍的当回合防御不能提前清除它。
- 水渍伤害计入"真实受伤"，可触发束缚受击解绑。
- 与灼烧 tick 同回合并存时按顺序结算（灼烧在前）。

## 6. 防御体系与反弹汇总

### 6.1 防护层级（单次受击结算伪码，自上而下命中即止）

```
对每个伤害事件 ev（src → t）：
  if ev.ap 且 t 开着荆棘之墙   → 击碎墙，伤害+1，不反弹        （木墙特例）
  elif t 开着荆棘之墙 且 !ev.ap → 伤害归零，登记反弹1           （木墙）
  elif t 开着荆棘岩   且 !ev.ap → 伤害归零                      （荆棘岩免疫；AP 照常穿过）
  elif defended[t]            → 伤害归零                        （防御完全免疫非穿防）
  elif t 有岩壳 且 src ≠ t     → absorb=min(层数, 伤害)，逐层扣除 （AP 完全无视岩壳）
  结算 hpDelta[t] -= 剩余伤害
```

- 防御回合岩壳完全不参与结算、不掉层；自伤（烈焰爆发反噬）不吃自身岩壳。
- 灼烧 tick 与水渍 tick 本身无视防御，也不经上述管线。

### 6.2 反弹统一规则

| 来源 | 反弹量 | 触发条件 | 频率 | 与穿甲弹交互 |
|:---|:---|:---|:---|:---|
| 木·荆棘之墙 | 1（走伤害管线，可被防御） | 墙未被击碎且使用者未防御 | 每攻击者每回合 1 次 | 击碎墙：无反弹、伤害+1 |
| 土·荆棘岩 | 2（有岩壳 3 并耗 1 层） | 使用者被攻击过 | 每攻击者每回合 1 次 | **照常触发** |
| 土·岩脉共鸣 | 1（无视防御） | 使用者防御且被攻击过 | 每攻击者每回合 1 次 | **照常触发** |

- 土系两类反弹为直接扣血；三种反弹各自独立判定，同一攻击者同一回合最多各吃一次。
- 反弹在双方行动结算后统一处理；使用者即使反弹中死亡，反弹依然生效（同步结算原则）。

## 7. 回合末结算顺序（引擎实现顺序，固定）

1. **岩脉共鸣自动凝聚** 1 层岩壳（回合开始）。
2. **动作合法性校验**：束缚三选一检查、可行性检查（含束缚不可叠加）→ 违规者强制改防御并记录 `forcedChanges`。
3. **使用结算**：扣资源、生成伤害/状态事件（金之斩挣脱在此即时解绑）。
4. **接取结算**：+1 元素（不受伤害打断）。
5. **伤害事件管线**：按 §6.1 逐事件处理；事件附带灼烧/种子附加、冲刷销毁（命中判定）。
6. **木墙反弹** 统一结算。
7. **荆棘岩反击**（每攻击者 2/3 伤，无视防御）。
8. **岩脉共鸣反震**（防御且被攻击过，每攻击者 1 伤，无视防御）。
9. **防御驱散**：灼烧/种子/水渍。
10. **灼烧 tick**（未防御，-1 无视防御）。
11. **水渍爆发**（未防御，-1 穿透）。
12. **种子偷取**（未防御，随机 1 元素转移）。
13. **受击解绑判定**：本回合开始时已束缚 && 真实掉血 >0 && 仍束缚 → 断裂。
14. **束缚递减**：本回合开始时 `bindTurns > 0` 者 -1。
15. **lastAction 记录**（以实际执行动作为准，被迫防御也会覆写）。
16. **HP 钳制** `[0, maxHp]`，生成战报。

> 状态是否触发以"本回合开始时"的快照为准，避免同回合重复触发。

## 8. 多人规则（引擎层已就绪，UI 待做）

- `new GameEngine(N)` 支持 2–9 人；动作可携带 `targets: [玩家下标]`。
- 双枪射击：多人必须分流两个不同目标（1v1 可集火同一人）。
- 火球雨：单一目标只能被指定 1 次，最多同时打 N 个不同目标。
- 单体路线默认打"第一个存活的其他玩家"。
- 胜负：最后存活者胜。

## 9. AI 行为模式（ai.js）

开局随机抽取一种、整局不变，加权随机挑选合法动作：

| 模式 | key | 倾向 |
|:---|:---|:---|
| 金匠 | `jinsmith` | 主接金 → 铸造三件套 → 射击输出 |
| 木控 | `woodkeeper` | 主接木 → 束缚/种子/荆棘（权重 3/2/2） |
| 火爆 | `firenova` | 主接火 → 火球/烈焰/灼烧/火球雨激进压血 |
| 水谋 | `watersage` | 主接水 → 渗透逼防、冲刷拆资源、泉水续航 |
| 磐石 | `stoneward` | 主接土 → 叠壳、荆棘岩、尽早岩脉永动 |
| 均衡 | `balanced` | 五系全 1 权重混合 |
| 防守 | `guardian` | 高频防御 + 木系反伤 + 少量水土辅助 |

- **斩杀优先**：对手 HP ≤ 1 时大幅提高各系补刀权重。
- **束缚中**（`boundAction`）：约 40% 概率用金之斩挣脱（需有金），否则 50% 复读上一动作，兜底防御。
- 合法性校验与引擎 `isActionFeasible` 同步（含"不对已束缚目标施放束缚"）。
- 当前 AI 为 1v1 视角（默认目标=第一个存活的其他玩家），多人 AI 待扩展。

## 10. 数据结构与常量（engine.js）

```javascript
// 玩家对象 makePlayer()
{
  id, name,
  hp: 3, maxHp: 3,
  elements: { Jin: 0, Mu: 0, Shui: 0, Huo: 0, Tu: 0 },
  weapons: { hasGatling: false, hasDualPistols: false, armorPiercing: 0 },
  status: {
    bindTurns: 0, seedTurns: 0, seedOwner: -1, burnTurns: 0,
    wetTurns: 0, shellLayers: 0, hasVein: false, lastAction: null
  }
}
```

常量：`MAX_ELEMENT = 9`、`MAX_HP = 5`、`MAX_SHELL = 5`、`GATHERABLE_ELEMENTS`（五系全开）、自体路线集合 `SELF_ROUTES = { Shui.spring, Tu.shell, Tu.thornRock, Tu.vein }`。

结算报告 `report` 字段：`p1_hp_change` / `p2_hp_change`（前两名兼容字段）、`hpChanges[]`、`actions{p1..pN}`（归一化后实际动作）、`forcedChanges[]`（player/from/to/reason）、`log_message`、`winner`、`state`、`players`（深拷贝快照）。

## 11. 测试基线

- `npm test` → `node engine.test.js`：**84 项通过 / 11 项跳过**（跳过项为废弃的旧"气"系统占位）。
- 覆盖：判定表、五行全部路线、束缚全细则（三选一/不可叠加/受击解绑/金之斩挣脱/复读接取）、防御新规、半点 HP、多人引擎层（3 人局分流/校验/胜负）、AI 七模式合法性。
