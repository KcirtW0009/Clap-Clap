# Clap-Clap 拍手对战 · Spec V3.0 — 水 / 土定稿与全局规则修订

> 承接 GAME_SPEC_001.md（金/木/火 定稿）。本版开放 **水（Shui）、土（Tu）**，五行齐备。
> 同时包含两项**全局规则修订**：① 防御改为完全免疫非穿防伤害；② HP 引入半点单位。
> 冲突处以本文档为准。

## 1. 全局规则修订 A：防御 = 完全免疫非穿防伤害

- **旧规**（V2.0）：防御使每个伤害事件 -1（最低 0）。
- **新规**（V3.0）：选择防御后，本回合**所有非穿防（`ignore=false`）伤害事件全额归零**；穿甲弹（`ignore=true`）照常穿透。
- 防御的其余职能不变：驱散灼烧/寄生/**水渍**、规避水渍判定。
- **连带影响清单**：
  - 烈焰爆发（3伤）vs 防御：2 伤 → **0 伤**（唯一被改变的既有结算）；
  - 加特林/双枪为逐发独立事件，新旧规则下均为 0，无变化；
  - 灼烧 tick、水渍 tick 本就“无视防御”，不受影响。

---

## 2. 全局规则修订 B：HP 半点系统

- 内部允许 **0.5 步进**（JS 数值精确表示，判定安全）。
- 初始 `hp = 3, maxHp = 3`；`maxHp` 上限 **5.0**（仅生命之泉可提升）。
- 所有伤害恒为整数；唯一产生半点的操作是生命之泉满血升级时的 **+0.5 回复**。
- 显示格式：整数显示 `n`，半点显示 `n.5`（如 `3.5/4`）；UI 心形容器按 `maxHp` 动态渲染，半点渲染半心。
- 胜负判定不变：`hp ≤ 0` 即败，钳制区间 `[0, maxHp]`。

## 3. 水元素（Shui）— 渗透 / 回复 / 资源转移

| 路线 | 消耗 | 效果 |
|:---|:---|:---|
| **水弹** | 1水 | 造成 1 伤害，可被防御（即被完全免疫）。 |
| **渗透** | 1水 | **无伤害，无视防御**。施加"水渍"（见下方时序）。施加本身不受荆棘之墙/荆棘岩影响（无伤害事件，同藤蔓束缚先例）。 |
| **冲刷** | 2水 | 造成 1 伤害（可被防御）。**若命中（目标本回合未选防御）→ 从目标的 金/木/火/土 中随机销毁 1 枚元素**（不扣水；销毁而非转移）。若目标开启荆棘之墙/荆棘岩将伤害完全格挡，则视为未命中，不销毁。岩壳吸收伤害不影响命中判定。目标四系元素皆空则无事发生。 |
| **生命之泉** | 2水 | 自体路线。若 `hp < maxHp`：回复 **1**（钳制于 maxHp）。若已满（`hp === maxHp`）：`maxHp += 1`（**上限 5.0**），并回复 **0.5**。已满且 maxHp 已达上限时，回复被钳制为无效（浪费）。 |

### 水渍（wet）时序与细则

```
第 N 回合：A 对 B 使用渗透 → B 获得 1 层水渍（可被防御动作无视施加本身）
第 N+1 回合结束时结算：
  ├─ B 本回合选择了防御 → 完全规避，水渍清除（不扣血）
  └─ B 未防御 → 受 1 点伤害（无视防御、无视岩壳），水渍清除
```

- **叠加规则：只刷新一层**——重复施加不叠层，水渍保持 1 层直到结算回合。
- 水渍 tick 与灼烧 tick 可同回合并存，按顺序结算（灼烧在前）。
- 水渍伤害计入“真实受伤”，可触发束缚的**受击解绑**。
- 防御在**施加水渍的当回合**不能提前清掉它（判定发生在下一回合末）。

## 4. 土元素（Tu）— 防守反击 / 岩壳 / 后期永动机

| 路线 | 消耗 | 效果 |
|:---|:---|:---|
| **土弹** | 1土 | 造成 1 伤害，可被防御。 |
| **岩壳** | 1土 | 获得 **1 层岩壳（上限 5 层）**，超出部分浪费。被动：未防御时被普通攻击（非穿防）命中，每层抵消 1 点伤害并消耗对应层数。**穿防攻击完全无视岩壳（不抵消、不消耗层数）**。选择防御的回合岩壳完全不参与结算、不掉层数。自伤（烈焰爆发反噬）不吃岩壳。 |
| **荆棘岩** | 2土 | 自体路线。**本回合完全免伤**（非穿防伤害归零；穿甲弹仍可造成伤害）。本回合每有一个攻击者攻击过自己，该攻击者受到 **2 点反弹（无视防御）**；若拥有岩壳 ≥1 层，反弹提升为 **3 点并消耗 1 层岩壳**。 |
| **岩脉共鸣** | 3土 | **永久被动**：① 每回合开始时自动获得 1 层岩壳（上限 5）；② 选择防御且本回合被攻击过时，每个攻击者受到 1 点反弹（无视防御）。 |

### 单次受击结算顺序（伪码）

```
对每个伤害事件 ev（src → t）：
  if ev.ap 且 t 有荆棘之墙：击碎墙，ev.amount+1，不反弹            （木墙特例）
  else if t 有荆棘之墙 且 !ev.ap：伤害归零，反弹1给src             （木墙）
  else if t 开启荆棘岩 且 !ev.ap：伤害归零                          （荆棘岩免疫）
       else if defended[t]：伤害归零（新防御规）                   （岩壳不动）
       else if t 有岩壳 且 src≠t：absorb=min(层数,amount)，
              amount-=absorb，层数-=absorb                         （逐层吃伤）
  结算 hpDelta[t] -= amount
```

### 反弹统一规则（汇总）

| 来源 | 反弹量 | 触发条件 | 频率 | 穿甲弹交互 |
|:---|:---|:---|:---|:---|
| 木·荆棘之墙 | 1（可被防御减免*） | 墙未被击碎且使用者未防御 | 每攻击者每回合 1 次 | 击碎墙：无反弹、伤害+1 |
| 土·荆棘岩 | 2（有岩壳则 3 并耗 1 层） | 使用者被攻击过 | 每攻击者每回合 1 次 | **照常触发**（AP 伤害也正常生效） |
| 土·岩脉共鸣 | 1 | 使用者选择了防御且被攻击过 | 每攻击者每回合 1 次 | **照常触发** |

> *木墙反弹走旧伤害管线；土系两类反弹为直接扣血（无视防御）。
> 三种反弹各自独立判定；同一攻击者同一回合最多各吃一次。
> 反弹在双方行动同时结算后统一处理，使用者即使反伤中死亡，反弹依然生效（同步结算原则）。

## 5. 判定优先级增补

| 对方动作 | 结果 |
|:---|:---|
| 使用 vs 防御（新） | 非穿防伤害全部归零；灼烧/寄生/水渍在防御方身上按各自规则处理（灼烧先附加再驱散、种子驱散、水渍清除规避）；土系防御反弹、荆棘岩反弹照常结算 |
| 渗透 vs 防御（施加回合） | 水渍照常附加（施加无视防御），下回合末再判定 |
| 冲刷 vs 防御 | 伤害 0，元素不销毁 |
| 冲刷 vs 荆棘之墙/荆棘岩 | 未命中，元素不销毁（荆棘岩反弹照常） |

## 6. AI 行为扩展

| 模式 | 偏好 |
|:---|:---|
| **水谋型（watersage）** | 优先接取水 → 渗透磨血逼防、冲刷拆资源、残血/满血时用生命之泉续航 |
| **磐石型（stoneward）** | 优先接取土 → 叠岩壳、荆棘岩反击、尽早岩脉共鸣进入永动 |

| 斩杀优先 | 补刀池增加水弹/土弹低权重 |
