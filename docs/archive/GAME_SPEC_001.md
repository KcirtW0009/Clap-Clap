# Clap-Clap 拍手对战 · 元素系统 Spec V2.0

> 基于 MVP 版本（蓄-攻-防）的全面升级。移除“气”系统，全面替换为“五行元素”系统。
如果有编号更新的SPEC文档，请去阅读新的SPEC文档。
> **当前版本定稿元素：金、木、火。水、土待设计。**

---

## 1. 核心架构（不变）

- **回合制**：准备（选动作）→ 锁定 → 结算 → 重置。
- **三按钮结构**（每回合三选一）：

| 动作 | 效果 |
|:---|:---|
| **接取** | 从金/木/水/火/土中选择一种，获得 1 个该元素 |
| **使用** | 消耗已有元素，发动对应效果（具体见各元素路线） |
| **防御** | 本回合不获取/不消耗，受到的伤害 **-1**（最低为0） |

- **铁律**：一回合内只能选一个动作。**接取和使用不可在同一回合完成。**

## 3. 金元素（Jin）— 锻造 / 物理爆发 / 破防

| 路线 | 前置条件 | 消耗 | 效果 |
|:---|:---|:---|:---|
| **基础攻击** | 拥有 ≥1 金 | 1金 | 造成 **1伤害**，可被防御 |
| **打造加特林** | 拥有 ≥1 金，且未拥有加特林 | 1金 + **消耗本回合** | 获得永久武器“加特林” |
| **加特林射击** | 已拥有加特林 | 消耗 **任意数量** 金（可连发） | **每消耗1金 → 发射2枚子弹**（每枚1伤害），**集火单一目标**，可被防御（每枚独立减伤） |
| **打造双枪** | 拥有 ≥1 金，且未拥有双枪 | 1金 + **消耗本回合** | 获得永久武器“双枪” |
| **双枪射击** | 已拥有双枪 | 消耗 **1个** 金（**不可连发**） | 发射2枚子弹（各1伤害），**1v1可集火同一目标（2伤害）/多人必须指向不同目标**，可被防御 |
| **打造穿甲弹** | 已拥有任意武器 | 1金 + **消耗本回合** | 获得 **2枚** 穿甲弹（计数器 +2） |
| **穿甲弹射击** | 已拥有穿甲弹 ≥1 | 消耗 **1枚** 穿甲弹 | 造成 **2伤害**，**无视防御**（穿透一切防御效果） |

**金元素核心特色**：需要**预先投资回合**打造装备，后期获得物理爆发能力。加特林=屯弹一波流，双枪=稳定两发，穿甲弹=破防利器。

## 4. 木元素（Mu）— 控制 / 干扰 / 防守反击

| 路线 | 消耗 | 效果 | 说明 |
|:---|:---|:---|:---|
| **基础攻击** | 1木 | 造成1伤害 | 可被防御 |
| **藤蔓束缚** | 1木 | **无伤害**，**穿透防御**，**束缚目标2回合** | 被束缚者只能选“防御”、“金之斩挣脱”或“复读被束缚前一回合的动作”（不能接取/使用其他元素）。**束缚不可叠加**：已处于束缚状态的目标免疫新的束缚（施放无效且不消耗木） |
| **种子寄生** | 2木 | 造成1伤害（可被防御），**植入种子**，回合结束时**随机偷取对方1个元素**（持续**1回合**） | 对方可用“防御”动作**同时抵消伤害+驱散种子** |
| **荆棘之墙** | 2木 | **免疫本回合所有伤害**，**反弹1伤害**给攻击者 | 对**穿甲弹无效**（穿甲弹穿透一切防御） |

**木元素核心特色**：不追求直接伤害，而是通过**束缚/偷取/反伤**打乱对方节奏。种子寄生的核心价值在于“白嫖对方一个元素”，削弱对手资源。

## 5. 火元素（Huo）— 爆发 / AOE / 高风险高回报

| 路线 | 消耗 | 效果 | 说明 |
|:---|:---|:---|:---|
| **基础攻击（火球）** | 1火 | 造成1伤害 | 可被防御 |
| **火球雨** | **消耗所有火元素** | **每1火指定1个不同目标**，各造成1伤害（可被防御） | **1v1时只打1伤害**（多余火溢出）；**多人时最多同时攻击N个不同目标**；**单一目标只能被指定1次** |
| **烈焰爆发** | 2火 | 造成**3伤害**（可被防御），**自己受到1点反噬**（**无视防御**） | 高风险斩杀技。若未能击杀对手，自身残血。 |
| **灼烧烙印** | 2火 | 造成**1伤害**（可被防御），附加**灼烧状态**（回合结束时受1伤害，**无视防御**，持续**2回合**） | 灼烧可被目标**使用“防御”动作驱散**（驱散后剩余灼烧层数清零） |

**火元素核心特色**：火球雨=群体压血线（多人特供），烈焰爆发=赌命斩杀，灼烧烙印=慢性逼防。

**灼烧时序说明**：
- 第1回合：使用灼烧烙印 → 即时伤害结算（可被防御）→ 灼烧状态附加
- 第2回合开始：对方身上已有灼烧 → 若对方选防御，则防御结算时驱散灼烧，本回合不受灼烧伤害
- 若对方不防御 → 回合结束时受1灼烧伤害

## 6. 判定优先级（使用 vs 其他动作）

| 对方动作 | 结果 |
|:---|:---|
| **使用（攻击）** | 双方效果同时结算，各自承受对方伤害 |
| **接取** | 攻击方效果正常生效，接取方本回合**不获得元素**（被打断） |
| **防御** | 攻击方效果生效，但防御方伤害 **-1**（最低0）。特殊：灼烧驱散、种子驱散在防御结算时同时处理 |

## 7. 胜负条件

- 任意玩家 HP ≤ 0 → 该玩家败北。
- 多人模式：最后存活者胜。
- 同时归零 → **平局**。

---

## 8. 交互流程（“使用”按钮）

```
点击“使用”
    ↓
弹出当前拥有的元素列表（只显示数量 > 0 的元素）
    ↓
点击一个元素（如“金”）
    ↓
弹出该元素当前可用的所有路线（灰显不可用路线，如“无武器时不显示加特林射击”）
    ↓
选择一条路线 → 锁定 → 进入结算
```

## 9. AI 行为模式（框架）

AI 开局随机抽取一种行为模式，整局不变：

| 模式 | 偏好 |
|:---|:---|
| **金匠型** | 优先接取金→打造武器→囤弹爆发 |
| **木控型** | 优先接取木→束缚/种子→干扰对手 |
| **火爆型** | 优先接取火→烈焰爆发/灼烧→激进压血 |
| **均衡型** | 随机应变 |
| **防守型** | 优先防御+木系反伤 |

具体权重值待实现时调优。
